# Plataforma MentoriaPro

**Projeto Integrador IV – SENAC 2026**

## 1. Sobre o projeto

A MentoriaPro é uma plataforma desenvolvida para conectar jovens profissionais a mentores, proporcionando oportunidades de aprendizado, orientação profissional e desenvolvimento de carreira.

O sistema permite o cadastro de mentores e mentorados, além de funcionalidades relacionadas ao agendamento e gerenciamento de mentorias.

## 2. Objetivo

Desenvolver uma plataforma web que facilite a conexão entre profissionais experientes e jovens que buscam orientação para seu desenvolvimento profissional.

## 3. Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização das interfaces.
- **PHP:** desenvolvimento do Back-end.
- **MySQL:** gerenciamento do banco de dados.
- **XAMPP:** ambiente de desenvolvimento local.
- **GitHub:** versionamento e colaboração no projeto.

## 4. Estrutura do projeto

```text
plataforma-mentoria/
│
├── backend/
│   ├── api/
│   ├── config/
│   ├── controllers/
│   ├── models/
│   └── arquivos de testes PHP
│
├── frontend/
│   ├── css/
│   ├── pages/
│   └── index.html
│
└── README.md
```

## 5. Funcionalidades

- Cadastro de mentores.
- Cadastro de mentorados.
- Login de usuários.
- Visualização de mentores.
- Perfil do mentor.
- Agendamento de mentorias.

## 6. Ambiente de desenvolvimento

Para executar o projeto localmente, é necessário:

1. Instalar o XAMPP.
2. Iniciar os serviços Apache e MySQL.
3. Disponibilizar os arquivos do projeto no diretório `htdocs`.
4. Configurar a conexão com o banco de dados MySQL.
5. Acessar a aplicação pelo navegador.

## 7. Execução do projeto

Após iniciar o Apache e o MySQL no XAMPP, acessar:

```text
http://localhost/plataforma-mentoria/frontend/
```

**Observação:** o endereço poderá variar conforme a organização dos arquivos no ambiente local.

## 8. Versionamento

O projeto utiliza GitHub para controle de versão, com separação do desenvolvimento em branches:

- `main`: versão principal do projeto.
- `feature/backend`: desenvolvimento do Back-end.
- `feature/frontend`: desenvolvimento do Front-end.
